# AI Review Intelligence

Приложение для анализа отзывов клиентов с помощью ИИ (демо-режим).

## 🚀 Живое демо
[Открыть приложение]( https://ai-review-intelligence-cxm9nfcbpkvtkdru28zjj5.streamlit.app/)

## Возможности
- Загрузка CSV с отзывами
- Просмотр данных в таблице
- Статистика по тональности
- Визуализация распределения
- ИИ-анализ (демо-режим) с оценкой точности

## Запуск локально
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите: `streamlit run app.py`

## Технологии
Python, Streamlit, Pandas

## Оценка

- Тест-кейсов: 5 (файл `test_reviews.csv`)
- Точность классификатора: 100.0% (5 из 5)
- AI-судья: средняя оценка 4.20 / 5 (оценка по шкале 1–5: релевантность, согласованность, формат)
- Guardrails: PII обнаружен и замаскирован в 1 отзыве (email → `[EMAIL]`)

## Ограничения

- Классификатор `classifier.py` — словарный (по ключевым словам), а не языковая модель. В демо-режиме без API.
- AI-судья в `app.py` — заглушка на правилах (совпало с эталоном → 5, не совпало → 3, без эталона → 4). Для production нужен реальный LLM-судья с промптом из `prompts.py`.
- Кэш `@st.cache_data` ускоряет повторные прогоны, но не сохраняется между перезапусками.
- Для production нужно: подключить реальную модель, добавить конвейер оценки (RAGAS / AI-судья), мониторинг и расширенные guardrails (токсичность, PII на выходе).
